### 🗺️ 4. 疯狂但清醒 → 行动路线图
#### 📅 0-180天里程碑
| 阶段 | 核心目标 | 关键指标 | 清醒协议 |
|------|----------|----------|----------|
| **0-30天** | 搭系统+跑通MVP+首次公开输出 | 知识卡≥60 / MVP可运行 / 文章发布1篇 | 每日深度工作≥3h；屏幕外时间≥2h |
| **30-90天** | 技能产品化+建立分发+正反馈 | 首笔收入/10用户 / 星≥50 / 粉丝破500 | 每周砍1个低效动作；睡眠≥7h |
| **90-180天** | 网络效应显现+收入流稳定+认知自运转 | 月收入≥基础生活费 / 合作≥3次 / 知识库联动查询 | 每月1天数字断食；情绪波动记录 |

#### 🔒 防崩溃执行协议
- **节奏**：90天冲刺制（5天深度执行+1天复盘+1天彻底离线）
- **度量**：只看4个指标（代码提交数/文章发布数/产品迭代次数/收入或用户数）
- **熔断**：连续3天未达基准 → 强制降级目标；连续2周睡眠<6h → 停更1周
- **清醒原则**：不比较进度，不追风口，只盯“可复利动作”。疯狂是密度，清醒是边界。
