# docsify

#### 介绍
docsify 是一个基于 Markdown 的文档生成工具，它通过在运行时动态加载和解析 Markdown 文件来构建文档网站，无需预先生成静态 HTML 文件。‌

docsify 的核心优势在于其简单性和灵活性。用户只需创建一个 index.html 文件作为入口，并配合 Markdown 格式的文档内容即可快速启动项目。‌
